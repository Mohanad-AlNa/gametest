# ECHO – لعبة المزامنة الذهنية 🌊

لعبة جماعية تعاونية يلعبها 2-8 أشخاص معاً. الهدف هو التفكير بنفس الطريقة وتحقيق أعلى تزامن ممكن!

## 🎮 فكرة اللعبة

كل جولة تظهر **فئة واحدة** لجميع اللاعبين في نفس الوقت.  
كل لاعب يكتب **كلمة واحدة** في السر خلال 30 ثانية.  
بعد انتهاء الوقت تُكشف جميع الإجابات دفعة واحدة:

| نسبة التطابق | النقاط | المستوى |
|---|---|---|
| 100% | ⚡ 50 نقطة | PERFECT SYNC |
| ≥ 75% | 🔥 20 نقطة | Great Sync |
| ≥ 50% | 👍 10 نقاط | Good Sync |
| ≥ 25% | 💪 5 نقاط | Low Sync |
| < 25% | 😅 0 نقطة | No Match |

**الهدف:** تحقيق أعلى نقاط جماعية ممكنة في 8 جولات (الحد الأقصى 400 نقطة).

## 🚀 تشغيل اللعبة

### المتطلبات
- Node.js 18 أو أحدث

### خطوات التشغيل

```bash
cd game
npm install
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

### للتطوير (إعادة تشغيل تلقائية)
```bash
npm run dev
```

### تحديد المنفذ
```bash
PORT=8080 npm start
```

## 🌐 النشر على الإنترنت (Render / Railway / Fly.io)

1. ارفع المجلد `game/` كمستودع Git مستقل، أو انشر من المجلد الجذر وحدد `Start Command: node game/server.js`.
2. تأكد من تعيين متغير البيئة `PORT` (معظم المنصات تضبطه تلقائياً).
3. لا توجد قاعدة بيانات — كل الحالة في الذاكرة.

## 🏠 ميزات اللعبة

- **إنشاء غرفة**: المضيف ينشئ غرفة ويحصل على كود من 4 أحرف
- **الانضمام**: الأصدقاء يدخلون الكود للانضمام (حتى 8 لاعبين)
- **مشاركة الكود**: زر نسخ الكود بنقرة واحدة
- **مؤقت بصري**: دائرة تعد تنازلياً 30 ثانية لكل جولة
- **كشف الإجابات**: تُظهر جميع الإجابات مع تمييز التطابقات
- **تصميم عربي**: واجهة RTL بالكامل بخط Cairo
- **متجاوب**: يعمل على الجوال والحاسوب
