## 🕹️ كيفية اللعب

### الإعداد
1. تأكد أن **جميع اللاعبين** متصلون بنفس شبكة **WiFi**
2. شخص واحد يكون **المضيف** (Host) والباقون ينضمون

### خطوات اللعبة
| الخطوة | التفاصيل |
|--------|----------|
| 1️⃣ | المضيف يفتح اللعبة → يضغط **"إنشاء غرفة"** |
| 2️⃣ | يظهر **عنوان IP** — شاركه مع أصدقائك |
| 3️⃣ | كل لاعب يضغط **"الانضمام"** ويدخل عنوان IP |
| 4️⃣ | المضيف يضغط **"ابدأ اللعبة"** |
| 5️⃣ | يظهر **تصنيف** لجميع اللاعبين (مثلاً: أشياء حمراء) |
| 6️⃣ | كل لاعب يكتب **أول شيء يخطر ببباله** خلال 30 ثانية |
| 7️⃣ | من كتب **نفس الكلمة** مع لاعب آخر يحصل على نقاط |
| 8️⃣ | **الأكثر تخاطراً** مع الآخرين يفوز! |

---

## 🏆 نظام النقاط

```
إجابة مطابقة مع 1 شخص   = 10 نقاط لكل منهما
إجابة مطابقة مع 2 أشخاص = 15 نقاط للثلاثة
إجابة مطابقة مع 3 أشخاص = 20 نقاط للأربعة
إجابة منفردة (لا مطابقة)  = 0 نقاط
```

